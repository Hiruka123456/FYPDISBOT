# Bot Moderation Web Portal (Next.js / React)

This is the Next.js / React web dashboard for your Discord bot, built for seamless deployment on [Vercel](https://vercel.com).

## Getting Started Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploying to Vercel

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import this repository.
4. Set the **Root Directory** to `web` (if deploying the subfolder individually).
5. Click **Deploy**. Vercel will automatically build and host the Next.js app on a global CDN.
